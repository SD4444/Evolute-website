# Evolute style handoff

Drop this folder into your website project (or attach it to the AI building it) and say: "follow evolute-style-guide.md and use evolute-tokens.css as the design tokens."

- `evolute-style-guide.md` — the full written spec: palette, type scale, layout patterns, components, motion, voice.
- `evolute-tokens.css` — ready-to-import CSS custom properties + base classes (headings, eyebrow, stat, pill button, hairline grid, rise animation).
- `reference-proposal.html` — a real, self-contained page built in this style (the CFP proposal). Best source of truth for markup patterns; view it in a browser.
- Logo SVGs: `evolute-logo-ink.svg` / `evolute-wordmark-dark.svg` for light backgrounds; `evolute-logo-white.svg` / `evolute-wordmark-light.svg` for dark backgrounds.

Fonts: Space Grotesk (display, weight 400) + Inter (body) via Google Fonts — the import tag is in the style guide.
